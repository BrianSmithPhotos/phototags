## Key takeaways

- **Caveat on #1**: `gemini-3.5-flash` drafted the original ground truth (see
  `generate_ground_truth.py`) before it was hand-edited, so its top spot likely
  still carries some residual advantage. Directionally interesting, not decisive.
- **Production default holds up**: `gemini-2.5-flash` (current OpenRouter default)
  is 5th overall but by far the best cost/speed tradeoff — ~10x cheaper than
  `gpt-5.1` and ~13x cheaper than `gemini-2.5-pro` for only modestly lower scores.
- **Local vs. cloud, same weights**: `qwen2.5vl:72b` run locally (48 min, 0$,
  3.68/3.12) scores about the same as the identical weights hosted on OpenRouter
  (2.75 min, $0.09, 3.66/3.07) — running it locally buys zero quality for a 17x
  time cost.
- **Local models trail the strongest cloud models** on both axes (quality and
  speed) for this task.
- **`moondream:latest` is unusable** for this task — a smoke test confirmed it
  just echoes the prompt's placeholder JSON (`"k1"`, `"k2"`) rather than
  describing the image, consistent with its 19.5% error rate and 1.33 accuracy.

## Dropped from this round

- **`mistral-medium-3.5:latest` (local, 127.7B/~170GB)**: ran for 14+ hours
  without completing a single pass — impractical for this kind of sweep.
  Replaced with the OpenRouter-hosted `mistralai/mistral-medium-3-5` (#12 above).
- **`llama3.2-vision:11b` (local)**: blocked by an open Ollama regression
  (`unknown model architecture: 'mllama'`), not a transient issue — see
  [ollama/ollama#16490](https://github.com/ollama/ollama/issues/16490). Revisit
  once upstream ships a fix.
- **DeepSeek**: no vision-capable model currently available on OpenRouter, so it
  couldn't be included as a candidate.

## Re-running

Per-model generation results live in `eval/results/<model>.json` (gitignored,
regenerate with `uv run python eval/run_candidates.py`). Judge scores live in
`eval/results/judged/<model>.json` (committed) and are produced by
`uv run python eval/run_judge.py`, which batches all candidates for one image
into a single judge call to minimize image-token cost. `uv run python
eval/summarize.py` reads both directories and prints the table above.
